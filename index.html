Model and evaluation

150 trees · maximum depth 12 · minimum leaf size 5 · square-root feature sampling · seed 20.

Held-out evaluation uses the same 6,000 clients as Assignment 8.6. At threshold 0.50, the model detects about 35% of observed defaults.

Education codes 0, 5, and 6 map to 4. Marriage code 0 maps to 3. Nine categorical predictors are one-hot encoded and fourteen numeric predictors are unscaled.
